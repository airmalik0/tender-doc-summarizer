# Тендерный суммаризатор

Сервис извлечения ключевых условий из документации госзакупок.

Решение тестового задания №1: PDF с сайта госзакупок → FastAPI → LLM →
структурированная выжимка (сумма контракта, сроки, требования к исполнителю, штрафы).

Разработка ведётся в ветке `feature/tender-summarizer`.
